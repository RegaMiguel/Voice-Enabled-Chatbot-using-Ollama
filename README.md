This is a Voice-Enabled Chatbot using Ollama as its AI.

This is mini project developed for a portfolio purpose.

Work Flow

File execution -> Records voice for 4 seconds then transforms it into a file (input.wav) -> Transcribes the voice recording into computer readable format -> Ollama reads the transcribes .wav file, and responds with voice over.


REQUIREMENTS:

Ollama.exe || Download here: https://ollama.com/
